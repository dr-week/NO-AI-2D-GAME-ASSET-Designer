# Laya character decisions

Nine typed character-proportion questions and a validated result mapper are implemented.
Deterministic commands and a browser-local System 1 brief-to-proportion flow are wired to the
Character workspace. An optional review-first local model suggestion is wired for character
profiles; no model runtime is bundled and target-specific quality is unmeasured. This contract
does not cover animation generation. See [Laya research](../../research/laya-integration.md),
[issue I-001](../issues.md), and [contribution 0074](../contributions/0074-character-design-profile-decisions.md).
