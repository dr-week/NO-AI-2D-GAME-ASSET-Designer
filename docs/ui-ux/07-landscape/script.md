# UI-07 · Landscape templates

Status: Implemented. Compact local recipe manager in the Landscape drawer.

## Controls

Name + Save current scene; Load; Delete with confirmation; JSON Import/Export.

## Flow

Set scene, art style, palette, material, and seed → preview → save named recipe → load later or transfer a validated JSON backup.

## States

Empty library, saved recipes tagged by style/region, loading/error status, import/export success or error. Preserve scene settings, style ID, and seed on load.
