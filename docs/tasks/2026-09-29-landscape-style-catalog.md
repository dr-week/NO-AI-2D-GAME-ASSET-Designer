# Landscape style catalog

## Goal
Generate reusable, themed 2D landscape starters with repeatable settings.

## Complete
- Added Contemporary, Warli-inspired, and Mithila-inspired profiles with region/category tags.
- Added seeded SVG accents; randomize and saved recipes retain stable style IDs.
- Kept style metadata in code and recipes in local IndexedDB; no backend database.

## Limits
- Abstract inspiration only; not an authentic cultural-art reproduction.
- Catalog is landscape-only. Add profiles after research/review.
