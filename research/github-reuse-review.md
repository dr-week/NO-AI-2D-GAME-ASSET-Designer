# GitHub reuse review

Reviewed 2026-09-29 from upstream GitHub repos/docs. Prefer existing APIs; add dependencies only for a proven gap.

| Project | Fit | Decision |
|---|---|---|
| [animation-timeline-control](https://github.com/ievgennaida/animation-timeline-control) · MIT · TypeScript, no runtime dependencies | Canvas timeline, keyframe selection, pan/zoom; renderer is a timeline UI, not an animation engine. | Reassess against active `src/features/timeline/` before adoption; do not duplicate timeline work. |
| [SVG.js](https://github.com/svgdotjs/svg.js) · MIT · zero dependencies | SVG construction and manipulation; companion packages add draw, select, drag, resize, and path handles. | Defer: native SVG/Svelte covers current authoring. Add only if editing complexity demonstrates a gap. |
| [lottie-web](https://github.com/airbnb/lottie-web) · MIT | Playback renderer for Lottie JSON, not an authoring editor. | Defer until Lottie export is an explicit requirement; isolate behind a format adapter. |
| [SpriteForge](https://github.com/Wilson-Cheng/SpriteForge) · MIT | Local TypeScript/Canvas/WebGL2 rigging, timeline, project format, Spine-style export. | Workflow reference for future rigging; not a fit for current SVG motion feature. Early project; validate maturity before relying on it. |
| [Skeleton Rig Visualizer](https://github.com/frycz/skeleton-rig) · no license visible in repository root | Small browser editor separates skeleton, SVG attachments, motion JSON, keyframes, and animated-SVG export; position/scale interpolation is linear. | Architecture reference only. Do not reuse source or ship as a dependency until license and maintenance status are confirmed. |
| [SVG Character Animator](https://github.com/molauu/svg-character-animator) · MIT code; CC BY-NC example art | Browser Studio imports named SVG states; stable path IDs drive per-path morph/fade; includes anchors, easing, idle motion, debugging, and web/PNG/SwiftUI output. | Strong reference for a future state-morph module. Current timeline has no multi-state path morph or arbitrary SVG rig; no dependency or art reuse. |
| [svg-path-morph](https://github.com/Minibrams/svg-path-morph) · MIT · `parse-svg-path` MIT dependency | Compiles path states with the same command sequence and samples weighted interpolation. | Adopted for isolated Path Morph workspace. Rejects mismatched path topology; no compound-path/rig editor. Preserve both MIT notices; upstream code remains in `node_modules`. |
| [kjanat/svg](https://github.com/kjanat/svg) · MIT Rust/npm toolkit · pre-1.0 | SVG parser grammar, lint, formatting, colors, and editor language-server tooling. | Reference for future developer diagnostics. Not adopted: early API and Rust/prebuilt platform package surface exceed this bounded metadata check. |
| [Animated SVG Showcase](https://github.com/BlinkZer0/Ai-Generated-SVG-Examples) · root MIT; README also claims CC0 examples | Twenty standalone SMIL examples demonstrate synchronized attributes, transforms, spline easing, staggered loops, and path morphing. License scope conflicts; verify individual assets before reuse. | Technique reference only; current tracks cover transforms/easing. No runtime library needed. |
| [SVG Spinners](https://github.com/n3r4zzurr0/svg-spinners) · MIT | Compact 24×24 CSS and SMIL spinner variants; documents that inline SVG behaves more consistently than external-image use in WebKit and notes SMIL load timing. | Reference for small product-status motion and format review only. Do not add a dependency or bundle spinner art into the asset-creation workflow. |
| [line-md](https://github.com/cyberalien/line-md) · MIT | Maintains SVG/SMIL, CSS, and per-frame SVG variants for a common icon set. | Compare output-format trade-offs only; its icons and runtime are unnecessary for user-authored scenes. Check attribution and asset scope before bundling any files. |
| [SVG Animations gallery](https://github.com/nirnejak/svg-animations) · MIT | Example gallery built with React and Motion; shows the separation between an interactive showcase and exported editable artwork. | Reference only; React/Motion stack duplicates current Svelte timeline/SMIL model. |
| [Glaxnimate](https://github.com/KDE/glaxnimate) · GPL-3.0-or-later | Full desktop vector animation and format workflows. | Study UX only; no embedded source without a separate licensing decision. |
| [SVG-Edit](https://github.com/SVG-Edit/svgedit) · MIT repository | Browser SVG editor separates editor UI from reusable `@svgedit/svgcanvas`; current V7 integration is evolving and needs a fixed-size host. | Defer: too broad for the bounded primitive editor; reassess only when path editing is approved. Check dependency and per-file license notices before reuse. |
| [HTML5 Studio](https://github.com/sfw/html5-studio) · Elastic License 2.0, not OSI open source | Multi-format ad timelines, platform-specific exports, and preflight checks for size, duration, files, and remote requests. | Workflow reference for receiver-specific preflight. Do not copy or embed: license restricts hosted/managed service use; React/Konva/GSAP stack duplicates current app. |
| [tilings](https://github.com/Ginden/tilings) · Unlicense | Parametric periodic tiling, `<pattern>` SVG export, embedded metadata, tile-count cap, and coverage/performance checks. | Reference for bounded work limits and export traceability. Existing procedural tile module already covers seeded simple repeats; don't duplicate its large tiling catalog. |
| [Excalimate](https://github.com/excalimate/excalimate) · MIT | Separates project schema, animation core, player, and export runtime; action-first sequences compile to deterministic animation. | Study package boundaries only. Its diagram-first UI, media encoders, hosted player, and MCP service exceed this app's current requirements. |
| [Grida](https://github.com/gridaco/grida) · Apache-2.0 repository (check package licenses) | Rust/Skia/WASM canvas, SVG editor, schema-based document format, history and headless export; SVG editor and engine packages remain alpha. | Architecture reference for future persisted multi-node documents or renderer throughput; too large and unstable as a dependency for current small Svelte scenes. |
| [Graphite](https://github.com/GraphiteEditor/Graphite) · MIT or Apache-2.0 | Alpha, nondestructive layer plus procedural node workflows for vector/raster design. | Study workflow and node ownership; do not embed while current generators have small bounded catalogs and no editable graph requirement. |
| [svg.pathhandles.js](https://github.com/svgdotjs/svg.pathhandles.js) · MIT | Cubic Bézier (`C`) point/handle UI for SVG.js. Requires `@svgdotjs/svg.js` ≥3.2.4 and `@svgdotjs/svg.draggable.js` ≥3.0.6 for dragging. | Defer: narrow command support and a three-package imperative interaction stack. Compare against a bounded native path model before adoption. |
| [Paper.js](https://github.com/paperjs/paper.js) · MIT | Canvas-oriented vector scripting with SVG import/export; Node canvas path requires native Cairo/Pango dependencies. | Defer: different rendering/editing model and no current path-geometry requirement. Avoid native dependencies in the browser-first core. |
| [Rough.js](https://github.com/rough-stuff/rough) · MIT | Small Canvas/SVG sketch-style rendering for shapes and paths; seed option supports repeatable output. | Candidate for an opt-in sketch style in generated art; current users have not established this need. Prototype size/render cost first. |
| [opentype.js](https://github.com/opentypejs/opentype.js) · MIT | Browser font parsing and text-to-Bezier/SVG path conversion. | Candidate for outline-text export when typography portability is requested; adds font loading, licensing, and shaping considerations. |
| [Maker.js](https://github.com/microsoft/maker.js) · Apache-2.0 | Parametric 2D paths/layers; DXF, SVG, and PDF output for CAD/CAM and laser workflows. | Use only for a distinct technical drawing need with a named receiver; not needed for Vector Art. |
| [svg2pdf.js](https://github.com/yWorks/svg2pdf.js) · MIT | SVG-to-PDF conversion through jsPDF. | Conversion alone does not provide PDF/X, color profiles, spot colors, or production preflight. |
| [SVGO](https://github.com/svg/svgo) · MIT | Removes redundant SVG markup. | Optimize only when size measurements warrant; does not sanitize untrusted SVG or validate production. |
| [fflate](https://github.com/101arrowz/fflate) · MIT | Compact browser/Node compression and ZIP APIs; supports streaming and async compression. | No need while exports use bounded ZIP STORE and PNG frames are already compressed. Consider only after measured archive size or ZIP-reading needs justify dependency/runtime cost. |
| [JSZip](https://github.com/Stuk/jszip) · MIT or GPL-3.0 | Create, read, edit ZIP archives in browser and Node. | Broader archive API than current export needs; dual license. Defer until import/edit of arbitrary ZIPs is in scope. |

**Adopt now:** `svg-path-morph` for matching-command path interpolation only. Native SVG/Canvas and in-house archive writer fit the rest of current scope. Duplicate/reorder and named layers need no library. Custom easing uses the shared TypeScript curve model and SVG SMIL `keySplines`; no package needed. Keep `svg.pathhandles.js` as a candidate for approved path editing; SVG.js interaction ownership needs review before a prototype. SVG-Edit exposes a reusable canvas beneath a full editor but carries broader integration scope. Reuse workflows, not proprietary code/assets. Before reuse, inspect license, dependencies, compatibility, and bundle/runtime cost.
