# Contribution log

Numbered handoffs record ownership, checks, and limits. See [contributing](../contributing.md)
for the change workflow. The [task queue](../tasks/README.md) contains future work only.

## Record format

```md
# NNNN · Short change name
Status: active | complete
Owner: name

## Files
- `path/to/file` — change/ownership

## Checks
- `npm run check` — pending/pass/fail/not run

## Limits
- Remaining work or `None`.
```
