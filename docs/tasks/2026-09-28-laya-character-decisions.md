# Laya character decisions

Nine typed character-proportion questions and a validated result mapper are implemented.
Deterministic commands and a browser-local System 1 brief-to-proportion flow are wired to the
Character workspace. No model runtime or inference provider is connected. This contract does
not cover animation generation. See [Laya research](../../research/laya-integration.md),
[issue I-001](../issues.md), and [contribution 0016](../contributions/0016-character-system-one-contract.md).
