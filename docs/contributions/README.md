# Contribution log

One numbered file per nontrivial change. This is the handoff index, not a second spec.

## Workflow

1. Copy the next number; add a log before editing.
2. List exact paths. Mark shared paths `claimed` while active; agree before overlap.
3. Update the record when files/status/checks change.
4. Mark `complete` at handoff. Keep old records as history.

## Record format

```md
# NNNN · Short change name
Status: active | complete
Owner: name

## Files
- `path/to/file` — change/ownership

## Checks
- `npm run check` — pending/pass/fail/not run
- `npm run build` — pending/pass/fail/not run

## Limits
- Remaining work or `None`.
```
